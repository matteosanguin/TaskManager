# Linee Guida per i Contributi

Grazie per il tuo interesse nel contribuire al progetto TaskManager! Questo documento contiene le linee guida per contribuire al progetto.

## Come Contribuire

1. Forka il repository
2. Crea un branch per la tua feature (`git checkout -b feature/NomeFeature`)
3. Committa le tue modifiche (`git commit -am 'Aggiunta nuova feature'`)
4. Pusha il branch (`git push origin feature/NomeFeature`)
5. Apri una Pull Request
## Stile del Codice

- Segui le convenzioni di denominazione del progetto
- Scrivi codice pulito e ben documentato
- Aggiungi commenti dove necessario
- Scrivi test unitari per le nuove funzionalità

## Processo di Pull Request
- Assicurati che tutti i test passino prima di aprire una PR
- Mantieni le PR focalizzate su una singola funzionalità o correzione
- Aggiorna la documentazione quando necessario
- Rispondi ai commenti dei revisori in modo tempestivo

## Segnalazione di Bug

Usa la sezione Issues per segnalare bug. Includi informazioni dettagliate su come riprodurre il problema.

## Richiesta di Nuove Funzionalità

Usa la sezione Issues per richiedere nuove funzionalità. Descrivi chiaramente il valore che la funzionalità aggiungerebbe al progetto.
