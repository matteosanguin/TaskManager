# Authentication System

This document describes the authentication system implemented in the TaskManager application.

## Overview

The authentication system is based on ASP.NET Core Identity. It provides a local authentication system with a custom user entity, and supports both JWT token authentication for the WebApi and cookie-based authentication for the BlazorApp.

## Custom User Entity

A custom user entity `AppUser` is used, which inherits from `Microsoft.AspNetCore.Identity.IdentityUser`. It adds the following custom properties:

- `FirstName` (string)
- `LastName` (string)

The `AppUser` entity is defined in the `TaskManager.Infrastructure` project.

## IAuthService

The `IAuthService` interface, defined in `TaskManager.Application`, provides the contract for the authentication service. It has the following methods:

- `LoginAsync(string username, string password)`: Authenticates a user and returns a `LoginResponse` containing a JWT token.
- `RegisterAsync(RegisterRequest request)`: Registers a new user.
- `GetCurrentUserAsync()`: Gets the currently authenticated user.
- `UpdateUserAsync(UpdateUserRequest request)`: Updates a user's profile.

The implementation, `AuthService`, is in the `TaskManager.Infrastructure` project.

## JWT Authentication (WebApi)

The WebApi uses JWT token authentication. The JWT is generated by the `AuthService` upon successful login. The token is configured with the following claims:

- `sub` (user id)
- `jti` (unique token id)
- `nameid` (user id)

The JWT settings (issuer, key, expiration) are configured in `appsettings.json`.

## Cookie Authentication (BlazorApp)

The BlazorApp uses cookie-based authentication. The cookie is set by the `AuthController` upon successful login. The authentication state is managed by the `CookieAuthenticationStateProvider`.
